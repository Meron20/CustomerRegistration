# CustomerRegistration – Skapa kundkonto

Individuell inlämning i kursen Objektorienterad analys och design (PROG26, Nackademin).
En WinUI-app där en kund kan skapa ett kundkonto (US-07).

## Kör appen

**Krav:** Windows 10/11 och Visual Studio med stöd för .NET 10 och WinUI (Windows App SDK).

1. Klona repot: `git clone https://github.com/Meron20/CustomerRegistration.git`
2. Öppna **CustomerRegistration.slnx** i Visual Studio.
3. Välj **CustomerRegistration.Presentation** som startprojekt.
4. Starta med **F5**.

Kunderna sparas bara i minnet medan appen körs.

## Kör testerna

I Visual Studio: **Test → Run All Tests**, eller i terminalen: `dotnet test`
